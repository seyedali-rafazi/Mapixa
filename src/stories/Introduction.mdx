# 🗺️ Mapixa Storybook

Welcome to the interactive component workshop for **Mapixa**!

Mapixa is a high-performance, modular, and extensible suite of vector drawing, geodesic measurement, navigation, and layer management tools for **MapLibre GL JS** and **React** (`react-map-gl`).

---

## 📚 Storybook Navigation Structure

Explore all the features and capabilities in the sidebar:

### 1. 🌟 [Core / Mapixa (All-in-One)](?path=/docs/core-mapixa-all-in-one--docs)
- **Default**: Standard complete suite with drawing, measurement, navigator, and coordinates.
- **Dark Theme**: Deep dark styling (`color="#1e1e1e"`) with high-contrast Carto Dark Matter basemap.
- **Auto Save Mode**: Instant vector commits without modal popups.
- **With Custom Actions**: Injected action buttons inside after-draw dialogs ("Save to API", "Export GeoJSON").
- **Custom Corner Positions**: Custom toolbar, navigator, and coordinate placements.

### 2. 🎨 [Drawing Suite / Tools & Controls](?path=/docs/drawing-suite-tools-controls--docs)
- **Marker Tool**: Custom SVG pin body, inner icons (`pin`, `star`, `circle`, `square`), size, opacity, and labels.
- **Polyline Tool**: Multi-point lines with real-time rubberband tracking and geodesic distance (km).
- **Polygon Tool**: Closed polygonal boundaries with real-time spherical area calculations ($m^2$ and $km^2$).
- **Circle Tool**: Geodesic circles generated by dragging outward from a center point.
- **Rectangle Tool**: 2-corner diagonal bounding box with area metrics.
- **Freehand Drawing**: Fluid sketch pen streaming coordinates into GeoJSON LineStrings.
- **Intersection Detector**: Draw two intersecting lines; detects crossing coordinates with glowing markers.
- **Interactive Eraser**: Click any shape, line, polygon, circle, rectangle, or freehand stroke on canvas to delete it.

### 3. 🗂️ [Drawing Suite / Drawn Layer Manager](?path=/docs/drawing-suite-drawn-layer-manager--docs)
- Central vector management hub popover with dynamic count badges, shape icons, inline label renaming, camera locate / zoom-to-feature, individual & master visibility toggling, and z-index reordering.

### 4. 📐 [Measurement & GIS Tools / Extra Tools Suite](?path=/docs/measurement-gis-tools-extra-tools-suite--docs)
- **Distance Ruler**: Multi-segment geodesic tape measure with on-map segment distance tags.
- **Area Capture**: Drag-to-select marquee crop tool that exports high-res PNG canvas screenshots.
- **Go-to Coordinates**: Smooth camera fly-to jumper with coordinate validation.
- **Georeferenced Image Overlay**: Import raster blueprints, drone imagery, or site plans with scaling, rotation, and opacity sliders.

### 5. 🗺️ [Basemap & Overlays / Basemap Switcher](?path=/docs/basemap-overlays-basemap-switcher--docs)
- Dynamic base style switcher (Dark Matter, Positron Light, Voyager, OSM) + transparent marine & traffic overlays with custom opacity.

### 6. 🧭 [Navigation & Viewport / Controls](?path=/docs/navigation-viewport-controls--docs)
- **MapNavigator**: Home, Compass/North reset, Zoom In/Out, GPS Geolocation, and Box Zoom.
- **CoordinateDisplay**: Live cursor coordinates + interactive Crosshair Point Picker mode.
- **MapViewControl**: Native browser Fullscreen API toggle.

### 7. 👁️ [Layer Visibility / Controls](?path=/docs/layer-visibility-controls--docs)
- Show or hide individual shape layers dynamically preserving underlying data.

### 8. 🧩 [Extensibility / Custom Accordion & Buttons](?path=/docs/extensibility-custom-accordion-buttons--docs)
- Docking custom accordions, floating buttons, and POI shortcuts with direct access to the `maplibregl.Map` instance.
